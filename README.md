# AI Cost Dashboard

### See where your AI coding budget goes.

面向使用多种 AI 编程工具的个人开发者，探索「收集订阅与使用情况 → 整理成本 → 查看报告」的产品流程。

**阶段：产品原型。** 当前仓库不是自动读取各平台账单或实时统计 token 的通用成本平台；使用数据主要由用户填写。

## 从哪里开始

| 文件 | 用途 |
|---|---|
| [index.html](index.html) | 工具、订阅费用、使用程度与报告接收信息的表单原型 |
| [report.html](report.html) | 报告页面 |
| [report-card.html](report-card.html) | 精简报告卡片 |
| [scripts/](scripts/) | 报告生成脚本 |
| [package.json](package.json) | 已有报告生成与 demo 命令 |

先阅读页面和脚本即可理解流程，不必提交真实个人信息。
表单代码会向配置的外部 Supabase 服务发送提交内容；不要在未经核对的数据环境中填写真实邮箱或业务资料。

## 产品问题

- 多个订阅的总支出能否一眼看清？
- 订阅费用和实际使用程度不匹配时，报告能否帮助用户判断？
- 用户准备输入、核查报告的成本，是否小于获得的价值？

这些是待验证的产品问题，不是已经证明的节省比例或用户增长结果。

## 当前边界

- 没有在本文发布时验证在线服务、邮件交付、外部数据库权限或真实节省金额。
- 仓库现有 `npm test` 执行报告脚本的 demo，并不是完整自动化测试套件。
- 不能仅凭自报使用程度推断精确 ROI；需要明确数据来源和估算假设。
- 页面中的价格或工具选项不应当作当前官方价格表，使用前需重新核对。

## 下一步值得验证

以一份无隐私样例完成从输入到报告的完整路径，记录准备时间、误读、修正和是否帮助用户做出决定，再决定是否增加自动接入。
